### 2. `predicate_selection.py`

目的：

- 增加“谓词白名单”能力，用于实现真正的 NeuralGAR-only。

### 5. `BNlearning/pattern_bn_features.py`

目的：

- 修复 PPI 全量图中存在 self-loop 时，`networkx.core_number()` 报错的问题。
- 该问题在 `wo_order_embedding` 改为读全量 CSV 后暴露出来。

报错信息：

```text
networkx.exception.NetworkXNotImplemented:
Input graph has self loops which is not permitted
```

主要修改：

- 在 `augment_graph_structural_features()` 中，对临时 `networkx.Graph()` 删除 self-loop：

```python
undirected.add_nodes_from(graph.vertices.keys())
self_loops = list(nx.selfloop_edges(undirected))
if self_loops:
    undirected.remove_edges_from(self_loops)
```

注意：

- 这里只修改用于计算结构特征的临时 networkx 图。
- 不删除原始 `DataGraph` 中的边。
- 不影响 pattern matching / VSpawn / rule mining 的输入图结构。

效果：

- PPI 全量图存在 self-loop 时也能正常计算：

```text
degree
clustering_bin
core_bin
role
degree_bucket
```

- `wo_order_embedding` 在 PPI 上不再因为 self-loop 卡在结构特征增强阶段。

### 6. 当前 tau 参数实验逻辑说明

当前 `run_tau_sensitivity.py` 中：

```python
TAU_P_VALUES = (0.0, 0.05, 0.10, 0.20, 0.30, 0.50)
TAU_X_VALUES = (0.0, 0.02, 0.05, 0.10, 0.20, 0.30)
TAU_P_SWEEP_RELATIVE_TAU = None
```

含义：

- `tau_P` 控制 Pattern-BN 的 pattern extension 剪枝阈值。
- `tau_X` 控制 Predicate-BN 的 predicate / feature 剪枝阈值。
- `relative_tau` 是 Pattern-BN 的相对阈值，逻辑近似为：

```text
实际阈值 = max(tau_p, relative_tau * 当前候选最高分)
```

在 `tau_P` sweep 中将 `relative_tau=None`，是为了避免相对阈值盖过绝对 `tau_P`，使不同 `tau_P` 设置看不出差异。

3. PPI 在 `candidate_non_edges` 模式下可能仍然导出 0 条。

原因是：

```text
matched_synthetic_instances=0
```

这表示候选非边没有匹配到规则前件，不是脚本失败。PPI 更建议尝试：

```bash
--mode anchored_existing_edge_labeling
```

或：

```bash
--mode matched_existing
```
